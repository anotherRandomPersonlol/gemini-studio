# Gemini Studio

Single-file chat UI styled like Gemini. It talks to the Gemini, Claude and ChatGPT APIs directly from your browser using your own API keys.

- Keys are stored only in your browser (localStorage) and sent only to their own provider.
- Open `index.html` locally, or host it with GitHub Pages (Settings > Pages > Deploy from branch > main / root).
- Settings > API Keys > Test connection shows whether a provider is reachable.
