                About this app
              

              

                This is an unofficial, independently-built client — it is not made or endorsed by Google. It was built almost entirely with AI coding assistance. It runs entirely in your browser: your API key(s), chat history, and settings are stored only in this browser's local storage and are sent directly from your browser to the model provider's API — never to any server this app's author controls.
              

            


            

              

                
                What your API key means for your data
              

              

                Using this app doesn't change your data's treatment — the same terms apply as if you called the API yourself. Policies below are a general summary as of 2026, are simplified, and can change; check each provider's own current terms before relying on them.
              


              

                
Google Gemini API

                

                  On the free/unpaid tier (including most keys created in AI Studio), Google's terms allow your prompts and responses to be used to improve Google's products, and human reviewers may read them. On a paid, billing-enabled tier, Google states it does not use your prompts/responses to improve its products, and only retains them briefly for abuse detection.
                

              

              

                
Anthropic API (Claude)

                

                  Anthropic states commercial API inputs/outputs are not used to train its models by default, with limited retention (measured in days) for abuse monitoring. This is separate from — and more restrictive than — Anthropic's consumer Claude.ai app policies.
                

              

              

                
OpenAI API

                

                  OpenAI states API data is not used to train its models by default (opt-in only), with data typically retained up to 30 days for abuse monitoring unless you have a zero-retention agreement.
                

              


              

                Bottom line: if you're pasting sensitive information, prefer a paid/billing-enabled key over a bare free-tier key, and read the provider's own current data usage policy directly.
              

            


            

              

                
                Your data
              

              

                All chats live only in this browser's local storage — clearing site data, switching browsers, or a storage-quota issue can lose them permanently. Export a backup now and then, or move your history to another device.
